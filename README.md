# Chat App

A full-stack real-time chat application with user authentication, instant messaging, and profile management.

Built with the MERN stack + Socket.io for real-time communication.

## Features

- **User Authentication** — Signup, Login, Logout with JWT
- **Real-time Messaging** — Instant chat using Socket.io
- **Online Users** — See who's currently online
- **Profile Management** — Update profile picture (Cloudinary)
- **Theme Support** — Light/Dark themes
- **Responsive UI** — Built with Tailwind CSS + DaisyUI
- **Protected Routes** — Auth-based route protection

## Tech Stack

### Frontend
- React 18 + Vite
- Tailwind CSS + DaisyUI
- Zustand (state management)
- Socket.io Client
- React Router
- Axios
- Lucide React icons
- React Hot Toast

### Backend
- Node.js + Express
- MongoDB + Mongoose
- Socket.io
- JWT Authentication
- Cloudinary (image uploads)
- bcryptjs
